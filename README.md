# Finance Management AI Agent · 本地 AI 财务管理系统

> **纯本地、数据不出机**的 AI 财务单据处理系统：上传发票 / 银行流水 → 自动识别提取 → 人工审核 → 对账 → 复式记账 → 三张 IFRS 财务报表 → 导出带审计轨迹的 Excel。
>
> 全程离线运行、不调用任何云服务、不接外部大模型；识别与记账基于**确定性规则 + 本地 OCR**，可解释、可追溯、可复核。功能货币 USD，IFRS 口径，按月软关账。

---

## ✨ 亮点

- **一条龙财务闭环**：识别 → 审核 → 对账 → 记账 → 报表 → 导出，端到端打通。
- **隐私优先**：后端只监听 `127.0.0.1`，财务数据永不出本机，不用云、不用云端 LLM。
- **金额零误差**：全链路 `Decimal`，绝不用 `float` 处理钱。
- **复式记账内核**：借贷平衡**硬校验**（不平拒绝过账、绝不自动凑平）；应计 → 资金结算两段式；红冲、幂等、凭证号、明细辅助账与控制账户对账。
- **三张 IFRS 报表 + 勾稽**：利润表 / 资产负债表 / 直接法现金流量表，勾稽（资产=负债+权益、现金勾稽、科目归类完整）**不通过不出表**。
- **AI 绝不自动入账**：过账是人工显式动作，机器只给建议。
- **513 个自动化测试**，覆盖提取、对账、记账、报表全链路。

## 🧩 功能模块

| 模块 | 目录 | 能力 |
|---|---|---|
| 提取 Extraction | `extraction/` | 发票 / 银行流水识别：多格式（PDF/Word/Excel/图片/CSV/OFX/QIF/MT940/CAMT）、文本层优先 + 本地 OCR 兜底、多语言与多币种、水印/印章鲁棒、复杂版面消歧、字段级校验与置信度 |
| 人工审核 Review | `review/` | 待审队列、逐条确认/改错/拒绝（状态机、留痕不可篡改）、原件↔字段双向高亮定位、可编辑明细与会计分类、规则学习（人工确认才生效） |
| 对账 Reconcile | `reconcile/` | 发票↔银行流水自动匹配（1:1 / 1:N / N:1）、高可信一键批量确认、异常集中人工处理、防重复入账 |
| 总账引擎 Ledger | `ledger/` | 复式记账内核、科目表、应计过账、资金结算（手续费/预扣税/折扣/舍入净额差）、试算平衡、红冲、控制账户对账 |
| 报表中心 Reports | `reports/` | 利润表 / 资产负债表 / 现金流量表、三表勾稽校验、导出带审计轨迹的 Excel（取数轨迹 + 凭证轨迹） |
| 网关 Gateway | `gateway/` | FastAPI 本地 Web（上传/审核/对账/总账/报表页面 + API） |
| 共享层 Core | `core/` | 数据模型、SQLite、配置、存储、维护 |

## 🏗 架构

```
上传 → [extraction] 识别提取 → [review] 人工审核 → [reconcile] 对账
                                                        │
        [reports] 三张报表 ← [ledger] 复式记账(应计+结算) ┘
                    │
              导出 Excel(含审计轨迹)
```

- **规则即数据**：分类、过账、报表映射都由可配置、可审计的规则驱动，不用 LLM 做财务判断。
- **两段式记账**：发票阶段挂应付/应收（权责发生制），实际收付款时做资金结算（应付/应收↔银行 + 净额差）。
- **人在环中**：AI 只提取与建议，审核通过、过账、结算都由人显式触发。

## 🚀 本地运行（试用）

需要 Python 3.9+。

```bash
# 1. 依赖
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
pip install -r requirements-ocr.txt      # 可选：扫描件/图片 OCR（Mac 用 requirements-ocr-mac.txt）

# 2. 启动（仅监听 127.0.0.1，自动打开浏览器）
./start.sh
# 或： python -m gateway.launch      # 端口默认 8000，可用 PORT 环境变量覆盖
```

打开浏览器访问首页，即可上传发票 / 银行流水试用。Mac 用户也可直接双击 `启动.command`，Windows 双击 `启动.bat`。
详细操作见 [`使用说明.md`](使用说明.md)。

## 🔒 隐私与安全立场

- 数据全部留在本机；后端只绑 `127.0.0.1`，不对外暴露、不接云服务、不用云端大模型。
- 原始上传文件永久保留以备追溯；审核动作全程留痕、不可篡改。
- 本仓库**不含任何真实财务数据**（数据库、真实发票、上传件均不入库）。
